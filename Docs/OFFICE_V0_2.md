# OFFICE V0.2

## 목표

참고 화면처럼 한눈에 회사가 돌아가는 모습이 보이되, 더 작고 귀여운 가족회사 공간을 만든다. 캐릭터는 화면 장식이 아니라 실제 Transform과 CharacterController로 움직인다.

## 구역

- 입구·접수: 누나의 초기 고객 응대 자리
- 중앙 통로: 모든 업무 지점을 연결하는 막힘 없는 이동 축
- 업무 구역: CRT 컴퓨터와 유선 전화가 있는 책상 4개
- 회의 구역: 낮은 파티션과 테이블
- 휴게 구역: 소파, 낮은 탁자, 물통, 간식장
- 출력 구역: 팩스·프린터와 서류함

## 실제 이동 규칙

- 플레이어: WASD/방향키 직접 이동, 벽과 가구 충돌
- 누나/아빠·엄마 placeholder: 지정된 웨이포인트를 CharacterController로 실제 이동
- 경로: 접수 → 중앙 통로 → 책상 → 프린터 → 휴게실 → 회의실
- 도착: 지점별 업무/휴식 상태로 전환하고 일정 시간 대기
- 이동 애니메이션: 속도와 카메라 기준 방향을 사용해 4방향 도트 프레임 선택
- 계약 업무: 계약과 가족을 선택하면 회의·업무·출력 웨이포인트가 결정되고, 실제 도착과 체류가 끝난 뒤에만 계약 인시가 반영된다.

## 완료 조건

- 누나가 적어도 4개 업무 지점을 반복 이동한다.
- 부모 placeholder 두 명이 서로 다른 경로로 이동한다.
- 플레이어가 집에서 거리로, 거리에서 사무실로 직접 걸어 들어간다.
- 가구와 벽을 통과하지 않는다.
- 직교 카메라와 도트 렌더 효과가 실제 플레이 화면에 적용된다.

## 구현 결과

- 완료: 접수, 중앙 통로, 업무 책상 4개, 회의실, 휴게실, 프린터, 서류장, 화분
- 완료: 누나와 부모 placeholder 2명의 서로 다른 순환 경로
- 완료: CharacterController 기반 실제 좌표 이동과 가구 충돌
- 완료: 이동 방향에 따른 누나 8프레임 선택
- 완료: 고객 응대, 업무, 출력, 회의, 휴식 상태 라벨
- 완료: 직교 카메라, 마우스 휠 줌, 360 높이 포인트 렌더
- 완료: 시작 회사에서 고용하지 않은 직원 A·B를 제거하고 이동 agent를 누나·아빠·엄마로 고정
- 완료: 계약 작업 coordinator가 가족을 회의·업무·출력 지점으로 우선 이동시키고 완료 이벤트를 계약 인시에 반영
- 검증: 누나·아빠·엄마를 각각 30초 분량 Tick해 이동과 정거장 도착을 확인하고, 누나가 계약 출력 지점으로 0.5m 이상 실제 이동한 뒤 4인시를 완료하는지 검사
