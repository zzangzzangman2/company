## 6. 지금 환경에 대한 주의 두 가지

### 6-1. 워처와 git 소유권

`.git`이 `CodexSandboxOffline` 소유라 `godho` 계정으로는 git이 거부한다.
지금 워처는 환경 변수로 우회해서 띄웠고, **재부팅하면 그 설정이 사라진다.**

durable하게 하려면 한 번만 실행한다.

```powershell
git config --global --add safe.directory C:/Users/godho/Documents/Codex/family_company_unity
```

전역 git 설정을 바꾸는 것이라 사용자 판단이 필요해 자동으로 하지 않았다.

### 6-2. 새 스크립트를 추가하면 첫 빌드는 반드시 실패한다

Unity가 `.meta`를 생성하면서 빌드 지문이 바뀌어
`Canonical build inputs changed while Unity was building`으로 폐기된다.
워처는 debounce 후 자동 재시도하므로 실제로는 문제가 없지만,
**수동 빌드 시에는 한 번 더 돌려야 한다.**

`Tools\ValidatePrototype.ps1`을 먼저 돌려 `.meta`를 생성한 뒤 빌드하면 한 번에 끝난다.

### 6-3. 프리뷰 씬 등록이 날아갈 수 있다

`PrototypeProjectBuilder.cs:111`이 `EditorBuildSettings.scenes`를
`Prototype01` 하나로 **덮어쓴다.** 씬 빌더를 다시 돌리면
`OfficeTileMigrationPreview` 등록과 F9 기능이 사라진다.

그 줄에서 프리뷰 씬도 함께 유지하도록 고치는 것을 권한다.
메인 흐름이 타일로 바뀌면 이 문제 자체가 없어진다.
