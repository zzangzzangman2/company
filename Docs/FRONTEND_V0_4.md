# FRONTEND V0.4

## 목표

`simul`의 강한 타이틀 일러스트와 단순한 시작 동선을 계승하되, 가족회사의 2000년 소형 사무실 정체성과 PC 가로 화면에 맞춘다. 이미지 자체에는 글자와 버튼을 굽지 않고 Unity UI를 별도로 올린다.

## 화면 기준

- PC 기본 해상도: 1920×1080, borderless fullscreen
- Web 기본 해상도: 1280×720
- 창 모드: 1600×900, 창 크기 조절 허용
- 지원 원칙: 16:9를 기준으로 만들고 더 넓은 화면에서는 좌우 공간을 사용한다.
- 배경: 1.35 이상 가로 화면은 16:9 V2를 aspect-fill하고, 1.35 미만 compact 화면은 10:11 세로 V3를 aspect-fill해 레터박스를 만들지 않는다.
- 단축키: F11 전체화면 전환, ESC 게임 메뉴, Ctrl+S 현재 슬롯 빠른 저장

## 시작 화면

- 처음하기: 3개 슬롯 중 하나를 선택한다. 기존 슬롯이면 덮어쓰기 확인을 한 번 더 받는다.
- 이어하기: 수정 시각이 가장 최근인 저장을 바로 연다. 저장이 없으면 비활성화한다.
- 불러오기: 저장된 3개 슬롯의 회사명, 게임 날짜, 현금, 평판, 계약 수와 실제 저장 시각을 보여준다.
- 화면 설정: 전체 화면과 1600×900 창 모드를 전환한다.
- 종료: standalone player를 종료한다.

## 게임 중 메뉴

- 상단 가로 바: 회사명, 게임 날짜·시각, 현금, 평판
- 왼쪽 패널: 가족 4명의 나이·체력·신뢰·스트레스
- 오른쪽 아래: 현재 슬롯, 저장, 불러오기, 메뉴
- ESC 메뉴: 계속하기, 저장하기, 불러오기, 화면 설정, 메인 화면
- 메뉴가 열리면 `Time.timeScale`을 0으로 두어 플레이어와 NPC 이동을 멈춘다.

## 저장 슬롯

- 파일: `family-company-save-slot-1.json`부터 `family-company-save-slot-3.json`
- 저장 방식: 임시 파일 작성 후 primary 교체, 이전 primary는 `.bak`으로 한 번 보관
- 호환: 기존 `family-company-prototype-save.json`은 1번 슬롯으로 자동 인식
- 저장 내용: 기존 Save V2 의미 상태만 보존하며 UI 화면, 선택 슬롯, Transform은 저장하지 않는다.

## 타이틀 비주얼 정본

- 가로 배경: `Assets/Art/UI/Resources/Title/MoneyRain/money_rain_tycoon_background_v2.png`
- compact 배경: `Assets/Art/UI/Resources/Title/MoneyRain/money_rain_tycoon_background_portrait_v3.png`
- 생성: OpenAI 내장 imagegen
- 구성: 왼쪽 세로 메뉴 안전 영역, 오른쪽 가족 4인이 실제 업무를 수행하는 2000년 등각 도트 사무실
- 시대 소품: CRT, 유선 전화, 팩스·프린터, 플로피디스크, 바인더, 종이 계약서
- 정본 유지: 가족 4인의 승인 외형, 누나 맨발, 주인공·엄마를 향하는 CRT 화면과 키보드
- 금지: 이미지 안 글자·버튼·로고·워터마크. 실제 조작 UI는 Unity가 렌더한다.

### 2026-08-13 가로 타이틀 V2

- 활성 배경: `Assets/Art/UI/Resources/Title/MoneyRain/money_rain_tycoon_background_v2.png`
- 구성: 왼쪽 42% 짙은 청록 메뉴 안전 영역, 오른쪽 가족 4인이 서로 다른 업무를 수행하는 2000년 등각 도트 사무실
- 정본 교정: 누나는 맨발이며, 앉아 있는 주인공과 엄마의 CRT 화면·키보드는 각 사람을 향한다.
- 조작 UI: 새 회사/이어하기/불러오기/화면 설정/종료를 왼쪽의 작은 5행 세로 메뉴로 표시한다.
- 유지: 투명 돈다발 3종·12개 인스턴스·2.8초 루프. 배경 이미지에는 글자·버튼·돈을 굽지 않는다.

### 2026-08-13 Compact UI V3 — 폐기된 중간안

- compact 기준: 화면 가로세로비 1.35 미만. 검증 기준 해상도는 실제 사용자 캡처와 같은 440×481 및 768×1024다.
- 상단: 활성 V2 배경 전체를 16:9 히어로로 표시해 가족 4인, 누나 맨발, 주인공·엄마의 사람 방향 CRT/키보드를 보존한다.
- 하단: 둥근 패널 안에 2개 주요 타일과 3개 유틸리티 타일을 배치한다. 긴 5단 번호 목록과 하단 단축키 줄은 compact 화면에서 사용하지 않는다.
- 돈다발은 히어로와 메뉴 뒤에서 기존 12개/2.8초 루프로 계속 움직이고 조작 UI는 항상 그 위에 렌더한다.

### 2026-08-13 Minimal UI V4 — 폐기된 중간안

- `새 회사/이어하기`만 낮은 둥근 버튼 2개로 표시한다. 번호, NEW/CONTINUE 배지와 항목별 설명은 표시하지 않는다.
- `불러오기/화면 설정/종료`는 테두리 없는 텍스트 메뉴 한 줄로 표시하고 종료만 코랄 텍스트로 구분한다.
- 외곽 메뉴 패널과 단축키 줄을 제거한다. 날짜·가족 수·창업 자금과 현재 알림은 얇은 구분선 아래 두 줄만 사용한다.
- compact와 가로 화면 모두 같은 메뉴 위계를 사용하며 기존 저장·화면 전환·종료 동작은 변경하지 않는다.

### 2026-08-13 Left Menu V5

- 메뉴 위치: 모든 화면 비율에서 왼쪽 세로형. 하단 메뉴 레이아웃은 사용하지 않는다.
- compact 440×481 기준: x 20px, 폭 190px, 행 높이 33px, 행 간격 5px. 가로 화면에서는 같은 비율로만 확대한다.
- 색상: 코랄 기본 선택, 크림 본문, 차콜 보조 버튼, 웜그레이 테두리. 민트·청록 버튼과 하단 리본은 금지한다.
- compact 배경의 중앙 16:9 scale-to-fit 방식은 V6에서 세로 V3 aspect-fill로 교체했다. 메뉴는 배경의 왼쪽 저복잡도 영역에 겹친다.
- 날짜·가족 수·창업 자금·알림은 왼쪽 하단의 코랄 구분선 아래 두 줄로만 표시한다.

### 2026-08-13 No-Letterbox V6

- compact 활성 배경: `money_rain_tycoon_background_portrait_v3.png`, 1195×1316.
- 1.35 미만 화면은 세로 V3를 aspect-fill해 검은 레터박스를 만들지 않는다. 1.35 이상 화면은 16:9 V2를 계속 사용한다.
- 세로 V3는 V2의 중앙 가족 사무실을 보존하고 위쪽 벽·창문과 아래쪽 바닥·식물만 확장한 이미지다. Unity UI와 돈다발은 이미지에 굽지 않는다.

## 검증 조건

- Unity 6000.3.21f1에서 전체 스크립트와 PrototypeValidation이 통과한다.
- 3개 슬롯을 서로 다른 seed와 시간으로 저장하고 각각 왕복한다.
- primary 재저장 시 backup이 생기고 기존 단일 저장을 1번 슬롯에서 읽는다.
- 시작 화면 → 새 게임 → 일시정지 → 재개 상태가 정확히 전환된다.
- Windows QA player에서 1920×1080 및 440×481 시작 화면을 실제 캡처해 잘림과 가독성을 확인한다.
