# SEATED CHAIR BACKREST V1 — 앉은 자세에서 등받이가 상체에 묻히는 문제

작성: 2026-08-14 / Claude
성격: **측정 결과 + 요청서**. 정본이 아니다.
측정 도구: `Tools/office_visual_coherence_v4_probe.py` (이번에 두 곳 수리함, 아래 4장)

---

## 0. 한 줄 답

> **의자 전경 레이어가 부품 마스크가 아니라 사각형 크롭이다.
> 그 사각형의 직선 경계가 캐릭터 몸 위에 그대로 그려진다.**

사용자 표현 그대로 "등받이가 보여야 하는데 상체랑 겹치는 느낌"이다.
겹치는 것은 등받이가 아니라 **크롭 경계선**이다.

---

## 1. 확정된 사실

### 1-1. 전경 스프라이트는 순수 사각형 크롭이다

`office_swivel_chair_front_v3.png`를 `office_swivel_chair_v3.png`와 픽셀 단위로 비교했다.

```
front == full AND x >= 317 AND y <= 413   (PIL 좌표)
front 픽셀 9881 / 가설 픽셀 9881 / 차이 0 / RGB 차이 0
```

부품을 골라낸 것이 아니라 바운딩박스로 자른 것이다.
`Assets/FamilyCompany/Editor/OfficeGrid/OfficeChairForegroundValidation.cs:97` 이 규칙을
**계약으로 못 박고** 있다.

```csharp
bool expectedForeground = basePixel.a > 0 &&
                          x >= ForegroundMinimumRuntimeX &&
                          y >= ForegroundMinimumRuntimeY;
```

즉 실수가 아니라 의도된 현재 계약이다. 그래서 아트만 고치면 게이트가 막는다.

### 1-2. 그 크롭이 실제 형상을 자른다

```
x=316/317 이음선을 걸친 의자 픽셀 : 182
y=413/414 이음선을 걸친 의자 픽셀 : 103
```

같은 물체가 두 평면으로 쪼개진다. 먼 쪽(북) 팔걸이는 절반만 전경으로 올라가고,
바퀴 기둥도 중간에서 끊긴다.

### 1-3. 그 직선 경계가 캐릭터 위에 그려진다

배송 스택(의자 베이스 → 인물 → 의자 전경 → 상체 재그리기)을 그대로 합성해서
골반 이음선 **아래**만 세었다. 그 위는 상체가 덮으므로 제외했다.

| 캐릭터 | 몸 위에 올라간 직선 경계 px | 사각형이 덮은 몸 px | 몸 대비 |
| --- | --- | --- | --- |
| father | 34 | 1348 | 4.5% |
| mother | **72** | 1846 | 5.8% |
| older_sister | 21 | 734 | 2.4% |
| player | **92** | 1822 | 5.7% |

손으로 그린 도트 캐릭터 위에 **21~92px짜리 완벽한 직선**이 지나간다.
직선은 픽셀아트에서 가장 눈에 띄는 인공물이다.

### 1-4. 등받이 자체도 몸을 감싸지 못한다

```
등받이가 좌판 위로 올라간 높이 : 87.5 world px  (의자 uniformScale = 1.0)
앉은 몸이 좌석 접점 위로 올라간 높이 : 192 ~ 231 world px
```

| 캐릭터 | 몸 높이 | 등받이/몸 |
| --- | --- | --- |
| player | 192~202px | 43~46% |
| father | 200~226px | 39~44% |
| mother | 206~211px | 42% |
| older_sister | 225~231px | **38%** |

등받이는 어깨날 아래에서 끝난다. 그리고 실제로 보이는 면적은 이렇다.

| 캐릭터 | 보이는 등받이 | 비율 |
| --- | --- | --- |
| player | 4169 / 6650 px | 63% |
| father | 2786 / 6650 px | 42% |
| older_sister | 2148 / 6650 px | 32% |
| mother | 1984 / 6650 px | **30%** |

어머니·누나는 등받이의 **70%가 가려진다.**

## 2. 배제한 원인

| 의심 | 측정 | 결론 |
| --- | --- | --- |
| 정렬 순서가 뒤바뀌었다 | 평면 상수 확인: 의자 베이스 1 → 인물 2 → 책상 전경 3 → 의자 전경 4 → 상체 5 | **아니다.** 순서는 정상이다 |
| 먼 팔걸이가 등을 가로지른다 | 프로브에 상체 평면을 넣자 막대가 사라졌다 | **프로브 산출물이었다.** 실제 게임에는 없다 |
| 방향별 앞뒤 판정이 없다 | `OfficeSeatForegroundOcclusionMode`가 `ignoredOcclusionMode`로 버려지고 있으나, 전경/상체 3계층이 그 역할을 대체한다 | 별개 정리 대상. 이번 증상의 원인은 아니다 |
| 좌석 앵커가 좌판을 벗어났다 | 좌석 접점을 좌판 앵커에 핀하는 계산을 재현했으나 명확한 이탈을 확인하지 못했다 | **미확정.** 근거 부족해 주장하지 않는다 |

> 코덱스가 만든 3계층 계약(전경 + 골반 이음선 상체 재그리기)은 잘 작동한다.
> 문제는 그 계층에 **사각형 마스크**를 물린 것뿐이다.

## 3. 요청

### 3-1. 전경 마스크를 부품 단위로 다시 만든다

```
지금 : 바운딩박스 크롭 (x >= 317, y <= 413)  -> 직선 경계가 몸에 찍힌다
목표 : 등받이 슬래브 + 가까운(남) 팔걸이만의 실루엣 마스크
```

**필수 조건**

1. 마스크 경계는 **의자 자신의 윤곽선만 따라간다.** 스프라이트를 가로지르는
   직선 절단이 하나도 없어야 한다. 직선이 없으면 몸 위에 직선이 찍힐 수 없다.
2. **한 물체를 두 평면으로 쪼개지 않는다.** 팔걸이든 기둥이든 전부 앞이거나 전부 뒤다.
   지금은 팔걸이가 182px 지점에서 갈린다.
3. 먼 쪽(북) 팔걸이는 앉은 사람 뒤에 있다. 전경에 넣지 않는다.

### 3-2. 검증도 같이 바꿔야 한다

`OfficeChairForegroundValidation.cs`가 사각형 규칙을 강제하므로 아트만 바꾸면 실패한다.
사각형 규칙을 **작성된 마스크 + 정확한 픽셀 수/해시** 검사로 교체해야 한다.
`ExpectedForegroundPixelCount`도 새 값으로 갱신한다.

### 3-3. 등받이 높이는 별도 판단이 필요하다

등받이를 키우면 골반 이음선 위는 상체가 덮으므로 **보이는 면적이 비례해서 늘지 않는다.**
등받이가 몸을 감싸 보이려면 몸 실루엣 **좌우로 삐져나와야** 한다.
지금은 등받이가 몸의 한쪽(동쪽)에만 붙어 있다.

이건 아트 방향 결정이라 수치만 남기고 판단은 넘긴다. 선택지는 셋이다.

| 안 | 내용 | 부작용 |
| --- | --- | --- |
| A | 등받이를 높인다 | 이음선 위는 안 보임. 체감 개선 제한적 |
| B | 등받이를 넓혀 몸 좌우로 삐져나오게 한다 | 의자 폭이 늘어 타일 점유 재검토 필요 |
| C | 의자 `uniformScale`을 올린다 | 바퀴·기둥까지 커진다 |

**B가 목표에 가장 직접적이다.** 카이로소프트에서 등받이가 읽히는 이유는 높이가 아니라
인물 실루엣 양옆으로 등받이가 보이기 때문이다.

## 4. 이번에 수리한 것 — 프로브

`Tools/office_visual_coherence_v4_probe.py`는 이 문제를 보려면 반드시 먼저 고쳐야 했다.

| 문제 | 조치 |
| --- | --- |
| 현재 main에서 **크래시**했다. `perimeter_cutaway_wall` 등 새 가구 종류에 PNG 매핑이 없어 `KeyError` | 매핑 없는 종류는 건너뛰되 **건너뛴 목록을 출력**한다. 조용히 삼키면 렌더가 완전한 그림인 것으로 오독된다 |
| 배송 스택의 **상체 재그리기(평면 5)를 모델링하지 않았다** | `MODEL_UPPER_BODY_REDRAW`로 골반 이음선 위를 의자 전경 위에 다시 그린다 |

두 번째가 특히 중요하다. 수리 전 프로브는 **실제 게임에 없는 팔걸이 막대가 등을 가로지르는**
그림을 냈다. 그 그림을 근거로 아트를 고쳤다면 없는 버그를 고치고 있었을 것이다.

`PROTECTION_BELOW_PELVIS_PX = 12`는 `OfficeSeatedUpperBodyProtectionRules.ProtectionBelowPelvisPx`의
사본이다. 한쪽을 바꾸면 다른 쪽도 맞춰야 한다.
