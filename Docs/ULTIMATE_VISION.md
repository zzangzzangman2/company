# ULTIMATE VISION

## 한 문장 목표

2000년의 작은 가족 하청회사를 시작해 실제 기업들과 같은 시장에서 경쟁하고, 제품·인재·특허·주식·인수합병을 이용해 2026년까지의 산업 역사를 플레이어의 선택으로 다시 쓰는 회사 경영 생활 시뮬레이션을 만든다.

## 시작 회사

- 시작일: 2000-01-03 08:00
- 형태: 가족이 운영하는 3차 웹·전산 외주/SI 하청회사
- 초기 업무: 소규모 홈페이지 제작·유지보수, 사내 전산 도구, 데이터 정리와 QA, PC·네트워크 관리, 번역·현지화
- 아빠: 계약 서명, 은행, 영업과 대외 책임
- 엄마: 회계, 급여, 구매와 현금 흐름
- 누나: 고객 응대, 일정, 운영과 현장 업무
- 플레이어: 기술, 제품 아이디어, 조사와 실제 사무실 행동

플레이어가 14살이므로 법률·금융 행위는 부모가 맡는다. 이것을 제한으로만 취급하지 않고, 가족 구성원을 설득하고 누구를 어디에 보낼지 정하는 핵심 게임플레이로 사용한다.

## 성장 사다리

1. 지역 업체의 3차 외주와 유지보수로 현금·평판을 확보한다.
2. 대기업 협력사의 2차 하청으로 들어가 품질·납기·보안 기준을 배운다.
3. 특정 기술이나 부품을 가진 1차 공급사로 성장한다.
4. 외주 과정에서 만든 도구를 자체 제품과 브랜드로 전환한다.
5. 투자 유치와 상장을 거쳐 실제 기업과 시장 점유율을 놓고 경쟁한다.
6. 우호적 인수, 공개매수, 합병, 자산 인수, 부실기업 인수로 산업 지도를 바꾼다.

## 핵심 재미 순환

계약 수주 → 사무실에서 실제 인력 이동과 업무 배정 → 납기·품질·가족 관계 결과 → 현금과 평판 획득 → 채용·연구·제품·주식 투자 → 경쟁 또는 인수합병 → 달라진 역사와 다음 기회

주식 화면만 보는 게임으로 돌아가지 않는다. 시장과 회계는 회사 공간에서 벌어지는 사람·업무·제품의 결과를 확대하는 시스템이다.

## 역사 캠페인 원칙

- 실제 역사상의 국내 회사·제품군·산업 변화·거시 충격을 첫 기준선으로 둔다.
- 역사적 사건은 날짜가 되면 무조건 재생되는 영상이 아니라 조건을 가진 후보 사건이다.
- 플레이어가 회사를 인수하거나 핵심 기술·인력을 선점하면 원래 사건은 취소, 지연, 대체 또는 다른 회사로 이전될 수 있다.
- 분기 후에도 세계가 멈추지 않는다. 경쟁 AI도 인수, 매각, 연구, 파산 대응을 계속한다.
- 현재 개발판의 회사명은 가명이 아니라 해당 날짜의 실제 법인명과 실제 통용명을 그대로 표시한다.
- 해외 대기업은 삭제하지 않지만 국내 회사 밀도가 충분해진 뒤 후순위로 추가한다.
- 향후 사용자가 별도로 이름 변경을 결정하기 전에는 가명 매핑을 만들거나 활성화하지 않는다.

## 개발 순서

1. 2000~2003년 국내 실제 기업 상세 데이터와 2000~2026 국내 기업 60개 이상의 등록부
2. 4인 가족이 처리할 수 있는 12~80 인시, 최대 2건의 소형 하청 계약과 닷컴 충격의 세로 조각
3. 자체 제품과 직원 성장, 기본 경쟁 AI
4. 주식·상장·주주·기업행동을 `simul` 설계에서 이식
5. 인수합병·자회사·파산·사업부·특허·고객계약 자산 인수
6. 국내 역사와 산업을 2026년까지 확장한 뒤 해외 기업을 단계적으로 추가

회사 등록부는 처음부터 넓게 만들되 모든 회사의 사건을 한 번에 상세화하지 않는다. 2000~2003년 국내 세로 조각이 재미있고 결정론적으로 재생되는지 먼저 검증한다.
