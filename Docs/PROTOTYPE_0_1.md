# PROTOTYPE 0.1

## 플레이 루프

1. 집에서 가족의 상태와 오늘 할 일을 확인한다.
2. 거리와 사무실을 이동하며 작은 업무를 처리한다.
3. 시간이 흐르고 가족의 피로, 관계, 회사 현금이 변한다.
4. 미성년 플레이어가 할 수 없는 계약이나 은행 업무는 가족에게 부탁한다.
5. 하루 끝에 회사 성과와 가족의 반응이 함께 돌아온다.

## 이번 구현 범위

- 집·거리·사무실 회색상자
- 플레이어 이동과 등각 카메라
- 가족 4명 상태, 시간 진행, 회사 현금, 복식부기 최소 모델
- 누나 정본 원화 배치, 부모 placeholder 자리
- 저장/불러오기 최소 경로
- 디버그 패널에서 1시간/1일 진행

## 범위 밖

- 최종 아트와 애니메이션
- 완성형 학교, 경제, 생산, 채용 시스템
- 최종 부모 외형과 성우/음성
- 모바일 입력과 출시 최적화
